# Exec Plans

作業中の複数ステップ計画を置く場所です
上位の入口と「いつ書くか」は `PLANS.md` を参照する

## 使い分け

- `active/`: 進行中の計画。**リポジトリにコミットしない** (gitignore)
- `template.md`: 計画の雛形 (コミット対象)

完了した計画の履歴ディレクトリは置かない
残すべき判断は ADR へ移し、手順メモは破棄する

## ファイル構成

1 タスクごとに 1 ファイルを作る

```
active/
  YYYYMMDD-<slug>.md
```

見出しは `template.md` に従う

## 運用ルール

- 長文にしない。実行に必要な情報だけを書く
- `active/` 配下はコミットしない
- 作業中に前提が変わったら更新する
- 将来を拘束する判断が固まったら `docs/adr/` に書く
- 完了後、計画ファイルは削除してよい。履歴として残さない
