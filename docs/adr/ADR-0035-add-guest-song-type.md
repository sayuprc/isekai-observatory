# 楽曲種別に参加曲を加える

## Context

楽曲種別は、初出 (原曲) が本人の歌唱かどうかでオリジナル曲とカバー曲の 2 つに分けていた

本人が他者名義の曲にコーラスや客演で加わった曲は、どちらにも当てはまらない

- オリジナル曲に入れると、本人名義ではない曲が本人の曲として並ぶ
- カバー曲に入れると、初出に関わっているのに既存曲を後から歌ったことになる

タイアップと違い、この違いは種別の軸そのものに関わるので、タグでは表せない

## Decision

- 楽曲種別の軸を「初出における本人の立場」に改め、参加曲 (`Guest` = 3) を加える
  - オリジナル曲: 初出が本人名義の歌唱
  - 参加曲: 他者名義の曲に、コーラスや客演などで加わっている
  - カバー曲: 初出に関わっておらず、他者の既存曲を後から歌っている
- コーラスと客演は分けず、参加の形は説明やタグで表す
- Remix や別バージョンが原曲の種別に従うルールは変えない

## Consequences

### Positive

- コーラスや客演で加わった曲を、定義を曲げずに登録できる
- 値の追加だけなので、登録済みの楽曲の移行は要らない

### Negative

- 種別の値を網羅して扱う箇所 (表示名、バッジの色など) に、参加曲の分を足す必要がある
- 参加の形 (コーラスか客演か) は種別から読み取れない
