# リリースの代表色を持たない

## Context

ADR-0015 でジャケットアートの代わりに、ジャケットから抽出した代表色を版ごとに 1 色持つことにした

閲覧サイトは代表色を次の場所で使っていた

- リリース一覧のカードの左の帯と、ホバー時の枠
- トップの最新リリースの上の線
- 楽曲詳細の収録リリースの色見本
- サムネイルがない楽曲タイルの背景

閲覧サイトの見た目を見直すなかで、代表色を外した画面と並べて比べた

カードの形と文字だけで区別でき、色がなくても困らなかった

代表色を保つには、版を登録するたびに画像から候補を出して人が選ぶ運用が要っていた

## Decision

- リリースの代表色を持たない
  - DB の `releases.color`、Admin API と Viewer API の `color`、管理画面の入力欄と画像からの抽出を削除する
  - 閲覧サイトは代表色を使った表示をやめ、サイト共通の配色で表す
- 権利者の画像を保存・配信しない方針 (ADR-0015) はそのまま保つ

ADR-0015 の代表色に関する部分と、ADR-0019 の代表色の置き場所に関する部分を置き換える

## Consequences

### Positive

- 版の登録で色を選ぶ手間がなくなる
- 管理画面から画像の色を抽出する依存 (node-vibrant) を外せる
- 閲覧サイトの色がサイト共通の配色だけになり、見た目がそろう

### Negative

- リリースを色で見分ける手がかりがなくなる
- 登録済みの代表色は列の削除で失われ、戻すときは入れ直す必要がある
