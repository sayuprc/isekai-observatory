# Event は時刻を保持せず日付で管理する

## Context

Event の開催時刻は記録元によって不明確または異なることがあり、すべての Event に時刻とタイムゾーンを与えると、推測した精度を構造化データとして扱うことになる。日付未定も正当な登録状態であり、予約日付を使うと検索や表示で実在の日付と混同する。

## Decision

- Event の開催時期は `Undated`、`Date`、`DateRange` のいずれかで表す
- Event は時刻・タイムゾーンを保持しない
- 判明している詳細な時刻は説明文に記載する
- 日付未定は明示的な `Undated` とし、`9999-12-31` などの予約日付で表さない
- 永続化では日付未定のための nullable を許容し、API では schedule の判別可能な構造として表す

## Consequences

### Positive

- 推測した時刻やタイムゾーンを事実として保存せずに済む
- 日付のソートや年フィルタを実際に判明している情報だけで行える
- 未定を実在する将来日付と混同しない

### Negative

- 時刻による並び替え、リマインド、時刻検索はできない
- 説明文に書かれた時刻は構造化された検索条件として利用できない
