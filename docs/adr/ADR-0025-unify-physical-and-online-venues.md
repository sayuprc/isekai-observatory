# 開催先は物理施設とオンライン配信プラットフォームを統合する

## Context

催しの開催先には、日本武道館のような物理施設と、Z-aN のようなオンライン配信プラットフォームがある。両者は固有情報やライフサイクルが異なる一方、管理者にとっては、催しを登録する際に「どこで開催・配信されるか」という同じ関心事から選択する対象である。

## Decision

物理施設とオンライン配信プラットフォームは、単一の開催先 (`Venue`) マスタで管理する。開催先は現地 (`physical`) またはオンライン (`online`) に分類する。個別の催しに属する視聴・チケット URL は開催先に含めない。

## Consequences

### Positive

- 管理者は現地とオンラインを同じ導線で登録・選択できる
- 現地開催とオンライン配信を併用する催しを、同じ関係の複数の開催先として表せる

### Negative

- 住所とサービス運営者のような、種別固有の情報は共通マスタだけでは表せない
- 種別固有の振る舞いが大きく増えた場合は、詳細モデルの分離を再検討する必要がある
